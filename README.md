# Frontier Hoops

Basketball shooting game where every ball is an RWA token from the $FRONTIER basket ($OPENAI, $META, $ANTHROPIC, $SPCX, $GOOG).

Pure HTML + Canvas + JS. No build step.

## Run locally
Open index.html, or `npx serve .`

## Deploy
Push to GitHub, import on Vercel. Framework preset: Other. No build command, output dir: root.

## Custom ball art
Put PNGs in tokens/ (openai.png, meta.png, anthropic.png, spcx.png, goog.png, frontier.png).
