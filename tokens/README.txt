Optional custom ball faces

Drop square PNG files here with these exact names and the game uses them
as the ball face (clipped to a circle, spinning with the ball):

  openai.png
  meta.png
  anthropic.png
  spcx.png
  goog.png
  frontier.png

Any file that is missing falls back to the drawn colored ball with the ticker on it.
Recommended size: 128x128 or 256x256.
